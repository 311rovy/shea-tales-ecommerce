# Shea Tales

An Awwwards-inspired brand presence and ecommerce experience for Ghanaian shea butter skincare.

## Direction

Shea Tales is built as a brand world first and a store second. The experience sells a core ritual of shea butter soap, lotion, and lip balm while also building memory around sourcing, texture, craft, and daily skin care.

## Features

- Full-screen editorial hero with video background
- Fullscreen cinematic menu with image-backed hover previews
- Brand manifesto and shea sourcing story sections
- Generated editorial imagery for source, texture, and lifestyle moments
- Ritual system built around Cleanse, Soften, and Seal
- Ritual quiz drawer with product and bundle recommendations
- Shop filters, wishlist controls, and image-to-video product hover reveals
- Rich product drawer with use, skin type, scent, texture, benefits, and ingredients
- Complete ritual bundle add-to-cart action
- Cart drawer with quantity controls, discount code, shipping, and totals
- Checkout panel with delivery/payment steps and confirmation state
- Shea Journal editorial preview
- Care, shipping, returns, FAQ, reviews, gallery, newsletter, and footer sections
- Scroll-triggered text and media reveal animations
- Responsive mobile layout

## Tech

- CSS
